# フェーズ B の手順シート: OBS での実機確認

## はじめに

OBS診断ちゃんプラグインを OBS Studio 33.0.1 で動かし、読み取りの正しさ・見た目・配布物を確かめるための手順です。OBS を使う作業はほかのセッションと競合するため、OBS を使う確認をこのシートにまとめました。依頼者が OBS の時間を確保し、上から順に操作してください。

計画の正本は `bd show obs-shindan-chan-plugin-zvx` のフェーズ B です。記録の欄は、このファイルに直接書き込んでください。Claude はこのファイルと OBS のログを読んで突き合わせます。

所要時間の目安は、B1 が 40 分から 60 分、B2 が 20 分、B3 が 15 分です。B1 のあとに Claude が修正を入れることがあります。その場合は、修正版の案内を受けてから B2 に進んでください。

## 準備

### 導入

1. OBS Studio を終了してください。
2. Claude が案内する PR の CI の成果物から、Windows x64 の ZIP をダウンロードして展開してください。
3. ZIP の中の `obs-shindan-chan-plugin` フォルダーを `C:\ProgramData\obs-studio\plugins\` へコピーしてください。

### 削除

ほかのセッションで OBS を使う前に、プラグインを外したいときの手順です。

1. OBS Studio を終了してください。
2. `C:\ProgramData\obs-studio\plugins\obs-shindan-chan-plugin` フォルダーを削除してください。

### プロファイル test の準備

本番のプロファイルを変えないよう、既存のプロファイル `test` を使います。

1. OBS を起動し、メニューの「プロファイル」から `test` を選んでください。
2. 「設定」の「配信」で、サービスを YouTube - RTMPS にし、YouTube Studio で用意した限定公開のテスト配信の配信キーを設定してください。
3. 同じ画面でサービスを Twitch に切り替え、「アカウント接続」で Twitch のアカウントを接続してください。接続すると「帯域テストモードを有効にする」のチェックボックスが表示されます。
4. メニューの「ドック」から「OBS診断ちゃん」を選び、ドックを表示してください。

## B1: 読み取りの実機確認

### 目的

配信の前にプラグインが組み立てた値が、配信中に OBS が実際に使う値と一致することを確かめます。突き合わせは Claude が OBS のログで行います。依頼者の操作は、設定の変更と、ドックの表示の記録です。

### 手順

各手順で設定を保存して設定の画面を閉じたら、ドックの表示が自動で更新されたかを記録してください。更新されなかったときは「診断をやり直す」を押し、その旨も記録してください。

| No. | 操作 | ドックが自動で更新された | 気づいたこと |
| --- | --- | --- | --- |
| 1 | 出力のモードを基本にし、映像のビットレートを 5000 にして「OK」で閉じる | | |
| 2 | 映像のビットレートを 6000 にして「適用」を押し、画面を閉じずにドックを見る。そのあと「OK」で閉じる | | |
| 3 | エンコーダーを x264 から、使えるハードウェアのエンコーダー (NVENC など) に変えて閉じる | | |
| 4 | 音声のビットレートを 128 に変えて閉じる | | |
| 5 | 出力のモードを詳細にし、配信のレート制御を VBR、キーフレームの間隔を 0、プロファイルを baseline にして閉じる | | |
| 6 | 「配信サービスのエンコーダー設定を適用する」をオフにして閉じる。もう一度オンに戻して閉じる | | |
| 7 | 配信に使う音声のトラックを 2 にし、トラック 2 のビットレートを 96 にして閉じる | | |
| 8 | 音声のサンプルレートを 44.1kHz に変えて閉じる。OBS を再起動し、もう一度ドックを見る。終わったら 48kHz に戻して再起動する | | |
| 9 | 配信のサービスを YouTube - RTMPS、Twitch、カスタムの順に切り替えて閉じ、ドックの配信先の選択を記録する | | |
| 10 | Twitch で「Enhanced Broadcasting」をオンにして閉じ、ドックの表示を記録する。終わったらオフに戻す | | |

### 配信の手順

次の 4 通りで、それぞれ配信を開始して 30 秒ほど待ち、停止してください。配信中と停止後のドックの表示を記録してください。Twitch では、配信を始める前に「帯域テストモードを有効にする」にチェックを入れてください。

| No. | モード | 配信先 | 設定 | 配信中の表示 | 停止後の表示 |
| --- | --- | --- | --- | --- | --- |
| S1 | 基本 | Twitch 帯域テスト | 映像のビットレート 8000 | | |
| S2 | 基本 | Twitch 帯域テスト | 映像のビットレート 8000。「配信サービスの推奨設定を無視する」をオン | | |
| S3 | 詳細 | Twitch 帯域テスト | 映像のビットレート 8000、キーフレームの間隔 4、サービスの設定の適用はオン | | |
| S4 | 詳細 | YouTube 限定公開 | H.264 以外のエンコーダーが使えればそれにする | | |

終わったら OBS を終了し、Claude に B1 の完了を伝えてください。

## B2: 診断の受入れ

### 目的

ランプとコメント、配信先の切替え、ボタン、英語の表示が、利用者にとって分かりやすいことを確かめます。

### 手順

| No. | 操作 | 期待する表示 | 結果と気づいたこと |
| --- | --- | --- | --- |
| 1 | 基本モード、1920×1080、60fps、x264、映像 6000、音声 160、48kHz、配信先 YouTube Live | 緑のランプ | |
| 2 | 詳細モード、サービスの設定の適用をオフ、レート制御 VBR、キーフレームの間隔 0 | 黄のランプと ▲ が 2 つ | |
| 3 | 2 に加えて、ドックの配信先を Twitch にし、プロファイル baseline、音声 192 | 赤のランプ | |
| 4 | ドックの配信先を YouTube Live と Twitch で切り替える | 基準と結果が切り替わる | |
| 5 | 「診断をやり直す」を押す | 結果が更新される | |
| 6 | プロファイルを test から別のものに切り替え、test に戻す | 結果が更新される | |
| 7 | OBS の言語を English にして再起動する。確認後に日本語へ戻す | 英語で表示される | |
| 8 | 全体の見た目、コメントの口調、目安の書き方 | 直したい点があれば書く | |

終わったら、公開してよい見た目とコメントになったかを Claude に伝えてください。直す点があれば、Claude が直したあとに該当する手順だけをやり直します。

## B3: リリース候補の確認

### 目的

配布する ZIP そのものが OBS に読み込まれることを確かめ、倉庫くんに載せる説明の画像を用意します。

### 手順

1. 「削除」の手順でプラグインを外し、Claude が案内する最終の ZIP で「導入」の手順をやり直してください。
2. OBS を起動し、ドックが表示されて診断の結果が出ることを確かめてください。
3. ドックの画面を撮影してください。形式は PNG か GIF で、容量は 1.5MB 以内、辺の長さは 4,096px 以内です。撮影した画像の場所を Claude に伝えてください。
4. 公開してよければ、その旨を Claude に伝えてください。

| --- | --- | --- |
| 1 | 最終の ZIP で読み込まれた | |
| 2 | 撮影した画像の場所 | |
| 3 | 公開の承認 | |
